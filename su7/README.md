# SU7 三维探索工作室

纯 HTML、CSS、JavaScript 与 Three.js 的可交互车辆展示。全部车身、车轮、内饰及场景几何由代码生成，无外部三维模型、图片贴图、字体或在线 CDN 请求。

## 运行

在仓库根目录运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

然后在同一台电脑打开 `http://127.0.0.1:8000/su7/`。页面使用 ES Modules，请通过 HTTP 访问，不要直接双击 HTML。要在手机浏览器访问，需部署静态站点或使用同一局域网中可访问的服务器；云机器的 localhost 不是公共网址。

## 操作

- 鼠标左键 / 单指拖动旋转，滚轮 / 双指捏合缩放，右键 / 双指拖动平移。
- 点击三维部件或部件清单，查看高亮、名称、核心说明和精度边界。
- 搜索名称、英文 ID、介绍或参数值；分类筛选外观、底盘和内饰。
- 四种模式：整车外观、透视结构、部件分解、线框视图。
- 五个视角、五种配色、自动旋转、标签及车灯开关。
- 在外观模式选择内部部件，会自动切换透视模式。

## 文件

- `model.js`：车身外观曲面、轮拱、灯组、玻璃、门缝和后视镜。
- `components.js`：程序化轮组与通用内饰、底盘示意。
- `app.js`：场景、材质、拾取、相机、标签、模式和面板交互。
- `parts.js`：17 个部件系统的中文介绍。
- `SOURCES.md`：参考资料、建模假设与精度边界。
- `vendor/`：Three.js 0.185.1 官方 npm 包中的必要文件及 MIT 许可证；完整性校验见 `VERSION.txt`。

场景不是官方数字样车。外观是依据两张照片制作的近似模型，隐藏结构为通用示意。模型尺寸、爆炸位移和灯光效果不应解释为实车技术参数。

## 部署

将 `su7/` 目录原样放在静态站点下即可。依赖均为相对路径，可部署于 GitHub Pages 的项目子路径，原有学习网站无需替换。

## 检查

```bash
node --check su7/app.js
node --check su7/model.js
node --check su7/components.js
git diff --check
```

浏览器验收应检查 WebGL 实际出图、模型部件拾取、旋转缩放、四种模式、筛选、配色、对话框及手机布局。自动化测试工具不属于网站运行依赖。
