# 初始版本检查记录

验证范围为 Chromium 软件 WebGL 和触屏模拟，不等同于实车结构校验或所有手机的性能保证。

已通过：

- JavaScript 语法和 Git 差异格式检查。
- 17 个部件系统生成，全部网格顶点为有限数值。
- 实际 WebGL 渲染、部件拾取、高亮、中文详情及分类/参数文字搜索。
- 整车、透视、分解、线框模式和五个视角。
- 鼠标真实拖拽旋转、滚轮缩放，配色、标签、车灯及自动旋转开关。
- 手机单指旋转、双指缩放；缩放结束不会误选部件。
- 手机清单及模型点击打开部件详情弹窗。
- 375、390、768、1440 像素布局无横向溢出。
- 减少动态效果偏好下，视角切换仍实际重绘画面。
- 操作/资料说明弹窗、Escape 关闭，以及图形上下文丢失提示和恢复。
- 页面运行时无外部资源请求、脚本错误或资源加载失败。

Three.js 为本地固定版本 0.185.1，下载后核对 npm 发布包 SHA-512 完整性值。未使用外部三维模型。

外观是照片参考下的近似复原，内饰和底盘采用通用示意，未声称已复原厂商 CAD、真实安装点或性能参数。参考与限制见 `SOURCES.md`。
