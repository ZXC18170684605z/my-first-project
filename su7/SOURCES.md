# SU7 程序化可视化：参考资料与精度边界

本页面是一份可交互的程序化外观与结构教学模型，不是小米官方产品页面，也不是工程 CAD。车辆几何由代码生成，不加载外部 GLB、GLTF、OBJ 等模型文件。

## 已使用的视觉资料

用户在本次对话中提供的两张照片：

1. 青色 SU7 前侧视角：用于参考低矮前舱、前灯轮廓、侧窗、车顶传感器外壳、轮毂和车漆观感。
2. 青色 SU7 后侧视角：用于参考溜背曲线、尾部肩线、贯穿式尾灯和后保险杠。

照片没有标尺，也未明确车型年份、版本或选装配置。单张透视图不能恢复精确三维曲率、板厚、安装点或隐藏结构。两张图片在此作为视觉参考，不作为尺寸测量、车型配置或性能参数的证据。

## 建模假设

- 外观采用约 5 m 车长、约 2 m 车宽和约 3 m 轴距的比例基准，方便建立可辨识的轿跑轮廓。这些是模型近似比例，不是独立核实后的官方尺寸。
- 车灯、分缝、门把手、轮毂、镜壳和玻璃曲面均经过简化。
- 内饰缺少照片支持，座椅、仪表台和方向盘属于空间布局示意。
- 底置电池、电驱、制动器及悬架采用通用电动汽车教学形态。展示前后电驱是一项双电机布局假设，不能据此判断参考照片中的 SU7 版本。
- 不展示未经核实的电池容量、电芯数量、驱动功率、加速成绩、风阻系数、激光雷达规格或供应商名称。
- 爆炸展示的位移、透视透明度、高亮颜色和灯光亮度是交互效果，不代表真实拆装顺序、材料参数或工作状态。

## 后续核对入口

小米汽车官方入口：[https://www.xiaomiev.com/](https://www.xiaomiev.com/)。核对实车参数时应选择明确的车型年份、版本和选装配置，并记录对应官方技术页面或手册版本。本次内容整理未独立获取和核验该官方站点页面，因此不把上述模型比例或任何隐藏结构称为已确认的官方数据。

若要继续提高精度，需要带标尺的正投影视图、前后左右及内饰细节照片，以及可合法使用的官方尺寸图或工程资料。公开拆解内容也需先确认车型版本、拍摄对象和证据出处，不能直接将其他版本的结构套用。

## 技术依据

- [Three.js 官方源码及许可证](https://github.com/mrdoob/three.js)：MIT；用于几何生成、材质、渲染和射线拾取。
- [OrbitControls 源码](https://github.com/mrdoob/three.js/blob/dev/examples/jsm/controls/OrbitControls.js)：用于鼠标与触屏视角控制。
- [Three.js 几何与材质文档](https://github.com/mrdoob/three.js/tree/dev/docs)：用于实现代码生成的场景，不作为车辆工程资料。

本次选型阶段已通过 GitHub API 核查 Three.js 的 MIT 许可证和官方 OrbitControls 示例。第三方依赖的许可证应随依赖文件保留。其他开源展厅和赛车项目的功能曾用于方案比较，但其车型、物理参数与结构数据不是本模型的实车证据。
