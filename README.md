# 尺寸研习所

简体中文汽车尺寸工程学习网站，使用原生 HTML、CSS、JavaScript，无需安装依赖或构建。

## 预览

直接在浏览器打开 `index.html` 即可使用。若要获得稳定的本地存储行为，建议在本地仓库目录运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

然后在运行服务器的同一台电脑访问 `http://127.0.0.1:8000`。云环境的回环地址不能从你的电脑直接访问；可将 `index.html`、`styles.css`、`app.js` 下载到同一个本地文件夹，再打开 HTML 或执行上述命令。无需发布网站。

## 功能

- DTS、RPS、GD&T、MCP 四个模块，各有基础概念、实际应用、常见误区和三道练习。
- 单选答题、即时解析、重新作答、正确题数进度和学习记录重置。
- 使用 localStorage 保存已提交答案，存储不可用时降级为当前页面内存记录。
- 适配手机和电脑；支持键盘导航、语义化表单及减少动态效果偏好。
- 无外部脚本、字体或图片请求，无账户及后端服务。

## 内容边界

DTS 按尺寸技术规范、RPS 按参考点系统介绍。MCP 暂按测量控制计划介绍，企业含义有差异，需核对项目文件。GD&T 仅涉及通用概念，不混用 ISO GPS 与 ASME 具体规则。示例数值为教学假设，不代表项目验收要求。

## 基本检查

```bash
node --check app.js
git diff --check
```

浏览器中检查四模块切换、答题反馈、刷新后记录恢复、重置，以及手机宽度下的布局。
